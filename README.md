# UI Basics Flutter

A beginner-friendly Flutter application demonstrating core UI concepts through five interactive tasks, including navigation, state management, forms, and static layouts.

## 📖 What's Inside This Project?

A 5-screen Flutter app demonstrating core UI concepts:

* **🏠 Main Menu (`main.dart`):** Uses `ListView` and `Navigator.push` for app routing.
* **1️⃣ Task 1 (`welcome_app.dart`):** Demonstrates `StatelessWidget`, widget centering, and text styling.
* **2️⃣ Task 2 (`interactive_button.dart`):** Introduces `StatefulWidget` and `setState()` for reactive UI updates.
* **3️⃣ Task 3 (`user_input_form.dart`):** Handles user data using `TextField` and `TextEditingController`.
* **4️⃣ Task 4 (`profile_screen.dart`):** Builds a static profile layout using `Column` and alignments.
* **5️⃣ Task 5 (`todo_list_ui.dart`):** Creates a structural UI skeleton for a task manager app.
